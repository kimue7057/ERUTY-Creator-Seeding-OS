# 회사 Chrome 전용 연락 실행기

ERUTY에서 확정한 Instagram DM을 회사 Chrome 프로필의 확장 프로그램이 받아 실제 화면으로 전송하고 결과를 돌려준다. Codex 데스크톱의 `@Chrome` 연결이나 별도 CLI의 Browser Use 기능을 넘겨받는 방식이 아니다. 분석·문장 작성은 기존 앱 기능을 유지하고, 확장 프로그램은 확정한 한 건의 전송만 실행한다.

## 설치와 연결

1. `0021_chrome_outreach_executor`와 `scripts/outreach-grants.sql`을 소유자 권한으로 적용한다. 기존 표·토큰·발송 이력을 바꾸지 않는다.
2. `pnpm build:executor` 또는 `pnpm build`로 공개 다운로드 ZIP을 만든다. 원본은 `extensions/instagram-executor`다. ZIP에는 명시한 확장 프로그램 파일 다섯 개만 들어가며 자격 증명은 포함하지 않는다.
3. 회사 계정이 로그인된 Chrome에서 `/settings/browser-executor`를 연다. ZIP 압축을 풀고 Chrome의 확장 프로그램 화면에서 해당 폴더를 로드한다. 설치·사이트 접근 권한은 사용자가 직접 확인한다.
4. ERUTY 관리자가 발신 계정을 선택하고 30일 연결 권한 확인란을 확인한 뒤 연결한다. 각 Chrome 프로필은 한 회사 계정에 연결한다. A/B 계정은 별도 프로필에서 각각 연결한다.
5. 확장 프로그램의 전용 Instagram 탭에서 실제 로그인 계정을 확인하고 서버에 보고해야 연락 버튼이 활성화된다. Chrome과 실행 PC가 켜져 있어야 한다. 다른 PC의 ERUTY 웹에서 요청해도 연결된 실행 PC가 처리한다.

배포 사이트는 `https://eruty-creator-seeding-os.vercel.app`로 고정한다. 도메인을 바꾸려면 서버 ID·허용 Origin과 확장 프로그램의 서비스/외부 메시지 허용 목록을 함께 검토한다. 확장 프로그램 공개키는 개발 로드 경로가 달라도 동일한 ID를 유지하기 위한 공개 메타데이터다. Chrome Web Store 게시·자동 업데이트는 별도 범위다.

## 권한과 전송

관리자 세션에서 만든 5분·1회용 연결 코드는 서버에 해시로 저장한다. 코드 교환은 지정 확장 프로그램 Origin에서만 받으며, 회사 계정 한 개에만 유효한 30일 토큰을 발급한다. 서버에는 토큰 해시만, Chrome에는 신뢰된 확장 프로그램 영역에만 토큰을 보관한다. SNS 로그인 쿠키·비밀번호·Meta 토큰은 사용하거나 전송하지 않는다. 확장 토큰으로 일반 발굴 API나 다른 회사 계정을 호출할 수 없다.

확장 프로그램은 자신이 만든 전용 Instagram 탭만 사용한다. 다른 탭을 열람하지 않고 Instagram의 내부 API·비공개 데이터·브라우저 디버거를 사용하지 않는다. 페이지·계정·수신 프로필·정확한 문장과 일회용 전송 권한을 확인하고 Send를 한 번만 누른다. 제한·CAPTCHA·로그인·계정 불일치는 중단한다. 화면 구조를 확인할 수 없어도 추측해서 보내지 않는다.

Chrome 알람은 약 30초마다 요청을 확인한다. 실제 응답 시간은 브라우저 실행 상태에 따라 달라지므로 즉시 실행을 보장하지 않는다. 최근 45초 준비 보고가 있어야 새 요청을 받는다. 앱의 상태는 10초마다 갱신한다.

프로필의 메시지 버튼은 페이지 제목보다 늦게 활성화될 수 있어, 준비될 때까지 최대 15초 동안 확인한다. 이 대기는 대화 열기에만 적용하며 Send는 재시도하지 않는다. 중단 시 프로필·메시지 버튼·입력창 단계를 구분한다. 진단 로그에는 고정된 버튼 이름·종류·활성 여부와 요소 수만 남기고, 페이지 본문·받은 메시지·비밀번호·쿠키는 받지 않는다. 개발용 폴더의 확장 프로그램을 업데이트한 경우 Chrome 확장 목록에서 ERUTY 실행기를 새로고침해야 새 코드가 적용된다.

확장 프로그램 갱신으로 기존 전용 탭의 content script 수신자가 사라졌으면, claim 전에 자신이 만든 탭만 한 번 새로고침해 연결을 복구한다. 로그인·CAPTCHA·계정 불일치는 복구 대상으로 취급하지 않는다. 로컬 저널이 있는 준비/전송 작업에는 이 복구 경로를 적용하지 않고 기존 중단·결과 불명 처리를 우선한다.

실제 연락 작업은 전용 Instagram 탭과 창을 활성화한다. 프로필의 Message 동작으로 사이트 탐색 메뉴에 새로 선택된 대화 원본 링크가 있으면, 팝업 입력창 대신 그 대화 화면에서 수신자를 다시 확인할 수 있다. 링크는 실제 사이트 메시지 아이콘의 HTTPS Instagram 대화 경로만 허용하며, 소개글 링크·추측한 대화 ID·다른 출처 URL은 사용하지 않는다. 수신자 헤더가 일치하기 전에는 본문을 입력하지 않는다.

본문 준비는 실제 입력창의 정확한 문장 일치로 확인한다. 입력 함수의 반환값만으로 성공·실패를 판정하지 않는다. 이미 승인 문장 그대로인 미발송 초안은 사용하지만 다른 내용은 지우거나 덮어쓰지 않는다. 같은 문장의 기존 회사 발신 메시지가 보이면 전송 전에 중단한다. 준비 실패 진단에는 고정된 세부 단계와 입력창의 비어 있음/일치/불일치 여부만 추가하며 초안 원문은 수집하지 않는다.

기존 불변 요청·claim·arm·중복 차단을 재사용한다. arm 요청 전부터 로컬 저널을 기록한다. 응답 손실·서비스 워커 종료 후에는 보내기 동작을 반복하지 않고 서버에 결과 불명으로 기록한다. 준비 단계 종료는 전송 전 중단이다. 확인된 발송은 대화창에 정확한 보낸 문장이 새로 나타나고 전송 중 표시가 사라진 경우에만 기록한다. 관련 발신 프로필·수신 헤더·문장 원문만 증거로 저장하며 받은편지함 전체를 수집하지 않는다.

ERUTY에서 연결 해제하면 토큰과 준비 상태가 즉시 무효화된다. 진행 중 준비 작업은 중단, 이미 arm된 작업은 결과 불명으로 보존한다. 확장 프로그램에서 해제해도 서버 해제를 먼저 완료해야 로컬 연결 정보를 지운다. 이미 발급된 짧은 전송 권한으로 실행 중인 클릭까지 되돌릴 수는 없으므로 해당 대화를 확인한다.

## 검증 범위

로컬 테스트는 합성 DOM·합성 계정과 실제 앱 API/DB를 사용한다. 실제 Instagram 발송 증거와 구분한다. 운영 검증은 확장 프로그램 설치·실제 회사 로그인·ERUTY 버튼 클릭·큐 claim·단일 전송·증거 저장·UI 결과를 동일한 요청 ID로 대조한다. 현재 배포/실제 전송 상태는 PR 검증 기록에 남긴다. 기존 대화 대상의 테스트와 처음 연락하는 대상의 메시지 요청도 구분한다.
