# OpenRouter 문장 작성과 템플릿

사용자 요청에 따라 실행 PC 없이 서버에서 생성한다. Codex 실행기 연동이나 별도 자동 발송은 추가하지 않는다.

## 연결

DB 소유자로 `0028_outreach_ai_settings`와 `scripts/outreach-grants.sql`을 적용한다. 기존 `OUTREACH_ENCRYPTION_KEY`를 유지한다. 조직 관리자는 **설정 → AI 문장 작성**에서 OpenRouter API 키와 모델 ID를 입력하고 **연결 테스트 후 저장**을 누른다. 기본 모델은 `openai/gpt-5.4-mini`이며 다른 모델 ID도 입력할 수 있다. 저장 전에 개인 정보 없는 짧은 실제 생성으로 인증, 모델 접근, JSON 출력 지원을 확인한다. 이 확인도 OpenRouter 크레딧을 사용한다.

키는 조직에 묶인 AES-GCM 암호문으로 저장한다. 화면·서버 액션·감사 기록에는 키와 암호문을 반환하지 않는다. 실제 DB 관리자 권한과 편집 revision을 검사한다. 키를 비워두고 모델만 변경하면 저장된 키를 사용해 다시 검증한다. 실패한 변경은 기존 연결을 보존한다. ‘AI 사용 중지’로 생성을 비활성화할 수 있다.

OpenRouter에는 고정된 HTTPS 주소만 호출하고 리디렉션을 따르지 않는다. `response_format: json_schema`, `strict: true`, `provider.require_parameters: true`를 사용한다. 키 인증, 크레딧 부족, 모델·형식 미지원, 요청 한도와 응답 오류를 고정된 안내로 구분한다. 외부 오류 본문과 키를 로그·사용자 오류에 포함하지 않는다.

## 작성

최종 선정된 크리에이터의 **연락하기 → 제안 문장**에서 채널·언어·목적을 선택한다. ‘분석 기반 문장 제안’은 해당 캠페인의 보존된 브랜드·제품, 크리에이터 분석과 실제 SNS 근거를 사용한다. AI의 제안과 작성 이유를 확인한 뒤 **이 문장 적용**을 눌러야 기존 본문을 바꾼다. 생성·연결 테스트는 실제 메시지를 발송하거나 선정 판정을 만들지 않는다.

출력의 근거 ID가 현재 후보의 실제 근거에 속하는지 검사한다. DM은 짧은 문단과 1,000자 한도를 지키며 HTML·미완성 변수는 거절한다. 미확인 시청자 지역, 보수·무상 제공·확정된 콘텐츠 범위·일정을 사실로 쓰지 않도록 지시한다. 모델 출력이므로 사용자가 원본과 상업 조건을 검토한다. 회사 계정·수신자·서명은 이후 단계에서 선택한다. API 요청은 기존 조직·사용자별 생성 빈도 제한을 유지한다.

## 템플릿

기본 문장은 이메일 8개(한국어·영어 각각 첫 제안, 브랜드 소개, 공식 제안, 후속 연락), Instagram DM 6개(각각 첫 제안, 제품 콘텐츠 제안, 후속 연락)다. 이메일의 네 가지 고정 디자인과 AI가 작성하는 문장은 분리한다. 템플릿은 캠페인의 실제 브랜드명을 사용하며 운영 회사 서명과 혼동하지 않는다.

설정에서 채널·언어별로 조회·편집한다. **기본 템플릿 보완**은 없는 이름·채널·언어 조합만 추가하고 기존 문장·서명·초안·발송 이력을 덮어쓰지 않는다. 보관한 기본 문장도 자동 복원하지 않는다. 작성 화면에서는 선택한 채널·언어의 템플릿을 보여 주며 확인한 콘텐츠 특징과 제안 이유를 넣어 적용한다. 후속 연락은 확인된 이전 발송이 있을 때 사용한다.

## 검증과 운영

합성 테스트로 암호화·조직 경계·관리자 권한·동시 수정·실패 시 기존 키 보존, 고정 API 주소·안전한 오류·JSON 거절 처리, 올바른 브랜드·SNS 근거·DM 문단과 원본 템플릿 보존을 확인한다. Playwright는 키 저장 후 비표시, 실제 서버 액션의 생성→검토→적용, 채널·언어 템플릿과 모바일을 검사한다. 실제 OpenRouter 사용 가능 여부는 회사 키를 사이트에 입력한 뒤 별도로 확인한다. 키가 없으면 연결 완료로 표시하지 않는다.

공식 규격: [인증](https://openrouter.ai/docs/api_reference/authentication), [구조화된 출력](https://openrouter.ai/docs/guides/features/structured-outputs), [오류 처리](https://openrouter.ai/docs/api_reference/errors-and-debugging).
