# 연결 설정·템플릿·초안 관리

## 범위와 완료 기준

선정 크리에이터의 분석 → 문장 작성 → 고정 디자인 선택 → 회사 계정·주소 확인 → 실제 메일 발송을 연결한다. 회사 앱의 최초 등록은 앱 안에서 완료할 수 있어야 하고, 초안·템플릿·서명을 다른 컴퓨터에서도 이어서 사용할 수 있어야 한다. 실제 개발자 앱 발급과 권한 동의는 외부 서비스에서 수행한다.

## 사용법

- **발신 계정 → 서비스 연결 설정**: 관리자가 Google·Instagram·TikTok 앱의 인증 정보를 등록한다. 팀원은 기존 발신 계정 카드에서 실제 서비스 로그인으로 계정을 연결한다. 앱 교체 시 이전 로그인 요청은 거절되고 계정은 재연결 필요로 표시된다.
- **템플릿·회사 서명 → 메시지 템플릿**: 기본 문장 4개를 설치하거나 새 이메일·Instagram·TikTok 텍스트 템플릿을 저장한다. 이름·언어·채널·본문·기본 디자인을 편집하고 복제·보관·복원할 수 있다. 보관은 과거 초안을 변경하지 않는다.
- **회사 서명·브랜드**: 회사 이름, 서명, 색상, HTTPS 웹사이트를 설정한다. 발신 이메일 주소는 실제 선택한 계정의 주소로 붙는다. 서명에 주소를 추정하거나 미확인 담당자를 넣지 않는다.
- **선정 명단 → 연락하기 → 제안 문장**: 저장된 문장 틀에 크리에이터·회사·캠페인과 사용자가 확인한 제안 이유를 채운다. 적용할 문장을 먼저 보여주고, 사용자가 적용한 경우에만 기존 제목·본문을 교체한다. 이는 템플릿 작성이며 AI 생성이라고 표시하지 않는다. AI 버튼은 별도 API 설정이 있는 경우에만 사용 가능하다.
- **템플릿·미리보기**: 개인화 레터 / 브랜드 소개 / 공식 제안서 / 짧은 후속 연락의 네 고정 디자인 중 선택한다. 디자인 변경은 본문을 변경하지 않는다. DM은 HTML이나 메일 서명을 붙이지 않는 텍스트 미리보기다.
- **계정·주소·발송**: 새로 로그인한 계정을 화면 이탈 없이 불러오고, 해당 계정에서 서비스가 확인한 주소만 선택한다. 미완성 `{{…}}` 항목은 발송을 차단한다. 실제 Send API 호출 전 선정·입력 버전·발신 주소·사용자 최종 확인을 다시 검사한다.
- **초안·발송 기록**: 크리에이터·캠페인·제목 검색, 채널·상태 필터, 페이지 이동, 이어서 작성이 가능하다. 명확한 발송 실패는 새 초안으로 복사해 수정할 수 있다. 결과 불명·발송 중인 기록은 복사와 재전송을 차단한다.

## 데이터와 운영

`0017`은 회사 앱 설정, 템플릿, 서명 테이블과 초안의 서명·언어·목적 스냅샷을 추가한다. 발송한 기록의 내용·서명·발신 주소는 DB에서도 변경을 금지한다. 템플릿과 서명 수정은 revision 충돌 검사를 적용한다. 회사 앱은 실제 DB 멤버십의 관리자만 저장 가능하며, 암호화 루트 키는 서버 환경변수에만 존재한다. 앱 설정은 OAuth state와 토큰의 fingerprint에 연결되며 다른 앱으로 교체해도 기존 토큰을 혼용하지 않는다.

운영 배포 전 소유자 역할로 마이그레이션을 실행하고 `scripts/outreach-grants.sql`을 적용한다. 루트 암호화 키를 교체하려면 모든 인증 정보를 먼저 재암호화하는 별도 작업이 필요하다. 기본 템플릿 설치는 조직별 1회이며 중복 호출에 안전하다.

## 검증과 제한

단위·DB 통합 테스트는 암호화, 조직·역할 격리, OAuth 앱 교체, 단일 사용 state, 승인된 주소, 중복 발송 차단, 서명 스냅샷 보존, 템플릿 충돌·복원, 미완성 문장 차단을 검증한다. 브라우저 테스트는 별도 합성 DB에서 JSON 가져오기 → 로그인 이동, 템플릿 저장·적용 → 디자인 변경 → 초안 재접속을 확인한다. 실제 회사 계정 동의와 수신함 도착은 합성 테스트로 검증했다고 주장하지 않는다.

Instagram은 로그인 연결, TikTok은 Login Kit 연결까지다. Instagram의 실제 DM 어댑터·대화 조건 확인과 TikTok Business Messaging 승인·어댑터는 미완료이며 실제 SNS 발송은 활성화하지 않는다. 메일은 Google 앱 등록·계정 동의를 완료해야 실제 전송할 수 있다. 회사 개발자 앱이 없는 상태를 연결 완료로 표시하지 않는다.
